# TaskFlow Todo App

TaskFlow is a full-stack task management application built with React Native and Node.js. It allows users to register, log in, create and manage personal tasks, track completion, and organize tasks using categories, priorities, filters, and sorting.

## Features

- User registration and login
- JWT-based authentication
- Secure password hashing with bcrypt
- Create, update, complete, and delete tasks
- User-specific task management
- Task categories
- Task priorities
- Due dates
- Task filtering and sorting
- Progress tracking
- Overdue task handling
- Session persistence
- REST API backend
- MongoDB database

## Tech Stack

### Mobile
